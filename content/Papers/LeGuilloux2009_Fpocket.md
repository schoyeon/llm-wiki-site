# Fpocket: An open source platform for ligand pocket detection
**Authors:** Vincent Le Guilloux, Peter Schmidtke & Pierre Tuffery
**Journal:** BMC Bioinformatics, 2009
**DOI:** 10.1186/1471-2105-10-168
## Summary
Fpocket은 Voronoi tessellation과 alpha sphere 기반의 오픈소스 pocket detection 도구. 3가지 프로그램(Fpocket, Tpocket, Dpocket)으로 구성. Holo 94%, apo 92%의 pocket detection rate. C 언어 구현으로 빠른 속도.
## Key Points
- Voronoi tessellation + alpha sphere 기반
- 오픈소스 (GNU GPL)
- 약물 설계 파이프라인의 초기 단계로 널리 사용
