# ScanNet: an interpretable geometric deep learning model for structure-based protein binding site prediction
**Authors:** Jérôme Tubiana, Dina Schneidman-Duhovny & Haim J. Wolfson
**Journal:** Nature Methods, 2022
**DOI:** 10.1038/s41592-022-01490-7
## Summary
ScanNet은 3D 구조에서 직접 원자/아미노산의 chemical environment를 학습하는 geometric deep learning 모델. Protein-protein, protein-antibody binding site, epitope 예측에 사용. SARS-CoV-2 spike epitope 검증 포함.
## Key Points
- End-to-end: 3D 좌표 → spatio-chemical features → binding site 예측
- Handcrafted features 불필요
- Protein-protein, protein-antibody, epitope 예측
- 웹 서버: bioinfo3d.cs.tau.ac.il/ScanNet
