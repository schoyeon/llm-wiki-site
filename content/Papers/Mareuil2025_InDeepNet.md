# InDeep^Net: a web platform for predicting functional binding sites in proteins using InDeep
**Authors:** Fabien Mareuil, Rachel Torchet, Luis Checa Ruano, Vincent Mallet, Michael Nilges, Guillaume Bouvier & Olivier Sperandio
**Journal:** Nucleic Acids Research, 2025
**DOI:** 10.1093/nar/gkaf403
## Summary
InDeep^Net은 단백질의 기능적 binding site를 예측하는 웹 플랫폼. InDeepHolo로 ligand-bound conformation의 propensity를 평가하고, PDB/AlphaFold 구조를 업로드하여 binding site 예측 가능. Mol* 기반 3D 시각화 제공.
## Key Points
- 웹 플랫폼: indeep-net.gpu.pasteur.cloud
- InDeepHolo: ligandability + holo conformation propensity 평가
- PDB, AlphaFold 구조 지원
- PPI target assessment + small-molecule binding site 예측
