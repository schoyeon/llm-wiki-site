# P2Rank: machine learning based tool for rapid and accurate prediction of ligand binding sites from protein structure
**Authors:** Radoslav Krivák & David Hoksza
**Journal:** Journal of Cheminformatics, 2018
**DOI:** 10.1186/s13321-018-0285-8
## Summary
P2Rank는 protein surface의 solvent accessible points에 기반한 ML 기반 ligand binding site 예측 도구. Template-free, stand-alone, 빠른 속도 (<1초/단백질). Fpocket, SiteHound, MetaPocket 2.0 등 기존 도구 대비 우수.
## Key Points
- Random forest 기반 — local chemical neighbourhood features
- Template-free, 외부 의존성 없음
- 빠른 속도: <1초/단백질, multi-threading 지원
- Java CLI + library로 제공
